The game plays this track only while a round or replay is active. It pauses during idle and result states.

## Boot and splash

| File | Screen moment | Source |
| --- | --- | --- |
| `boot-bed.mp3` | Four-second loading bed with a soft fade | Short derivative of "Sci-Fi Game" by Arulo under the Mixkit Stock Music Free License |
| `splash-reveal.mp3` | Three-note crystal resolve on the STACKS logo reveal | Original cue generated locally for this prototype |

The boot bed and splash resolve follow the automatic loader timeline when the browser permits startup autoplay. Browsers that block autoplay continue through the same clean visual flow without displaying an extra entry prompt. All startup audio stops before the game opens.
